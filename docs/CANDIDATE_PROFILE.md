## 2. Working model

The core working model is:

```text
business problem
-> requirements
-> architecture
-> decomposition
-> task for AI coding agent
-> diff review
-> testing
-> corrections
-> documentation
-> deployment / production
```

This working model is a stronger matching signal than a formal vacancy title.

## 7. Matching priorities

Strongest signals:

1. AI coding agents are part of actual engineering workflow.
2. Real projects/portfolio matter more than years of employment.
3. Employer accepts small commercial experience or judges by output.
4. Role includes ownership / end-to-end delivery.
5. Internal tools, automation, API integration or rapid MVP work.
6. Compatible product-development stack.

Technology overlap without the above is insufficient.

## 8. Profile anti-drift rule

If a ranking change makes ordinary senior Python/backend/frontend vacancies dominate merely because of stack overlap, the ranking is considered regressed.
